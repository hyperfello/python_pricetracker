
# Price Tracker

A Python learning project for fetching product pages, extracting prices, and tracking price changes over time.

## Current progress

- Fetch a webpage using `requests`.
- Parse HTML using BeautifulSoup.
- Store price history using SQLite.
- Compare current prices with previously recorded prices.
- Check products against a target price.

Some features are still being developed and tested.

## Requirements

- Python 3
- pip

## Installation

Clone or download this repository, then run:

```bash
python -m pip install -r requirements.txt
```

## Run

```bash
python price_tracker.py
```

The current web-fetch test uses Books to Scrape:
https://books.toscrape.com/
